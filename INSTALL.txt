# Cara memasang

1. Buka repository https://github.com/MikaaWebsite
2. Buka README.md.
3. Tekan Edit (ikon pensil).
4. Hapus semua isi README lama.
5. Buka file README.md dari paket ini.
6. Copy seluruh isinya.
7. Paste ke editor GitHub.
8. Pilih Preview untuk melihat hasil.
9. Jika sudah sesuai, pilih Commit changes.

Catatan:
- File yang dipasang adalah README.md, bukan HTML.
- Tombol/link di dalam README adalah link aktif.
- Jangan masukkan password, token, API key, atau secret.
