# MIKAA WEBSITE — README V3

## Struktur file

Upload struktur ini ke repository `MikaaWebsite`:

```text
MikaaWebsite/
├── README.md
└── assets/
    ├── hero.svg
    ├── arsenal.svg
    ├── projects.svg
    └── footer.svg
```

## Cara memasang lewat GitHub di HP

### 1. Download ZIP ini
Ekstrak ZIP di perangkat.

### 2. Buka repository
Buka:
`https://github.com/MikaaWebsite`

### 3. Upload folder assets
Masuk ke repository → **Add file** → **Upload files**.

Upload:
- `hero.svg`
- `arsenal.svg`
- `projects.svg`
- `footer.svg`

Pastikan semuanya masuk ke folder:

```text
assets/
```

Jika GitHub tidak membuat folder otomatis, buka **Add file → Create new file**, ketik:

```text
assets/.gitkeep
```

commit dulu, lalu upload file SVG ke folder `assets`.

### 4. Ganti README
Buka `README.md` → tombol pensil/Edit.

Hapus isi lama.

Buka file `README.md` dari paket ini, salin **seluruh isinya**, lalu paste.

### 5. Preview
Pilih **Preview**.

Yang harus terlihat:
- Hero neon purple
- MIKAA WEBSITE
- tombol OPEN TO WORK
- Arsenal besar
- panel skill warna biru/merah/ungu/hijau/orange
- Project Lab
- footer Connect

### 6. Commit
Kalau preview sudah benar:
**Commit changes**

Gunakan pesan:

`feat: redesign profile README v3`

## Penting

Jangan hapus repository.
Jangan ubah branch.
Jangan membuat repository baru.

Perubahan ini hanya mengganti `README.md` dan menambahkan 4 file SVG di `assets/`.

## Jika ada masalah

Jika gambar tidak muncul:
1. Pastikan nama file persis sama.
2. Pastikan folder bernama `assets`.
3. Pastikan file SVG sudah di-commit.
4. Refresh halaman GitHub.

Nama file harus:

```text
assets/hero.svg
assets/arsenal.svg
assets/projects.svg
assets/footer.svg
```
